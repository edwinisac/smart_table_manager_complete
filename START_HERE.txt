TABLEBOOK — START HERE

1) Start the Java API first:
   Linux / Pop!_OS:
     cd TableBook-backend
     ./run.sh
   Windows:
     cd TableBook-backend
     run.bat

2) Open a second terminal and start React:
     cd table_reservation
     npm install
     npm run dev

3) Open the localhost URL Vite prints, usually http://localhost:5173.
   Keep both terminals running.

Demo admin login: admin / admin123
Demo user login:  user / user123

The Java API defaults to http://localhost:8080/api. If port 8080 is occupied,
run `PORT=8180 ./run.sh` and create table_reservation/.env containing:
VITE_API_URL=http://localhost:8180/api
Then restart Vite.

JSON data is stored in TableBook-backend/data/. Keep these files to retain
users, tables and bookings.
